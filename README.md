
# Olist E-Commerce Business Intelligence & Analytics

## Project Overview
An end-to-end e-commerce data analytics project using Python, NumPy, Pandas, SQL, Power BI and DAX.

## Business Objective
To analyze e-commerce transactions, customer behavior, product performance, seller performance, payments, delivery operations and customer satisfaction.

## Technologies Used
- Python
- NumPy
- Pandas
- SQL (PostgreSQL)
- Power BI
- DAX

## Project Structure
- data/ – Local datasets
- notebooks/ – Python analysis
- sql/ – SQL queries
- dashboard/ – Power BI dashboard
- reports/ – Business insights
- screenshots/ – Dashboard screenshots

## Business Questions
1. How is overall sales performance?
2. Which product categories generate the most revenue?
3. Which sellers perform best?
4. Are orders delivered on time?
5. Does delivery delay affect customer satisfaction?
6. Which payment methods are most popular?
7. Which regions generate the most orders?
